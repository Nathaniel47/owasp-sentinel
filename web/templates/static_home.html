OWASP Sentinel

A hybrid scanner for the OWASP Top 10 (2025): static analysis (Opengrep with open rules) finds candidate vulnerabilities, and an LLM gives a second opinion on each to cut false positives. It is benchmarked on the OWASP Benchmark (Java) with known answers.

PRELIMINARY results. The LLM triage numbers below come from {{ t.runs_completed }} of 3 planned runs, so there is no run-to-run spread yet. Differences of a few points may be noise.
This page is a static, read-only demo. The live scanner (paste code, get findings) is not hosted here. It runs locally with Docker: see the README for the two commands.

What I built

  • Custom rules: a Java rule pack for SQL injection, trust boundary, weak randomness and XPath injection, the categories the open rules miss.
  • LLM triage pipeline: each finding and its code context goes to an LLM for a true/false-positive verdict. Only confident false positives are dropped, every call is cached, and fixes are checked by re-scanning.
  • Reproducible benchmark: pinned OWASP Benchmark commit, fixed-seed 450-case sample, scored against the official answers; categories without ground truth are marked "Not covered".
