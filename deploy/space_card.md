# OWASP Sentinel (demo)

Hybrid LLM + SAST scanner for the OWASP Top 10 (2025). Paste Java, JavaScript or
Python, or click an example. Code is only read, never run, and is not stored.

Benchmark results are **preliminary** until three triage runs finish; the app's
`/benchmark` page says so. Source: see the project repository.
